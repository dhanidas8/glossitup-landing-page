# glossitup.in — Luxury Pink Landing Page

A responsive, static lip gloss landing page designed for GitHub + Vercel. It uses plain HTML, CSS and JavaScript, so no build step or package installation is required.

## Preview locally
1. Download and unzip this folder.
2. Open `index.html` in a browser.

## Before publishing
1. Open `script.js`.
2. Replace `919999999999` in `WHATSAPP_NUMBER` with your business WhatsApp number in international format, with digits only. Example format for India: `919876543210`.
3. Update product names, prices, descriptions and shade artwork in `index.html` to match your actual products.
4. Replace the Instagram URL in `index.html` with your real brand profile.
5. Add genuine customer reviews only after you have permission to use them.
6. Check your actual product claims, ingredients, pricing, shipping and return policy before launch.

## Deploy to GitHub + Vercel
### GitHub
1. Create a new repository, for example `glossitup-landing-page`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Commit the files.

### Vercel
1. Sign in to Vercel and choose **Add New → Project**.
2. Import your GitHub repository.
3. For this static site, leave the framework preset as **Other** and leave the build command and output directory blank.
4. Click **Deploy**.
5. When ready, add your custom domain in the Vercel project settings and follow the DNS instructions.

## WhatsApp ordering
Each product button opens WhatsApp with a prefilled message. The customer still reviews and sends the message; this page does not process payments or confirm stock automatically.
